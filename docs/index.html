TOPOCHECK DOKUMENTATION

Einführung

TopoCheck ist eine Visual-Studio-Code-Erweiterung zum Erstellen, Generieren und Überprüfen von Netzwerkkonfigurationen.

Aktueller Stand

Diese Dokumentation ist eine vorbereitete Struktur und wird parallel zur Extension erweitert.

Was löst TopoCheck?

Die Erweiterung verbindet eine grafische Netzwerktopologie mit den dazugehörigen Gerätekonfigurationen. Änderungen und Fehler werden dadurch leichter nachvollziehbar.

Installation

  1. Visual Studio Code öffnen.
  2. TopoCheck aus dem Extension Marketplace installieren.
  3. Über die Befehlspalette ein neues TopoCheck-Projekt anlegen.

Die endgültigen Installationsschritte werden ergänzt, sobald die Extension veröffentlicht ist.

Erste Topologie

Geräte werden aus der Werkzeugleiste auf die Arbeitsfläche gezogen und anschließend über ihre Interfaces verbunden.

Automatische Konfiguration

TopoCheck analysiert Geräte, Verbindungen, Adressen und Protokolle. Daraus entstehen getrennte Konfigurationsdateien für jedes Gerät.

Fehleranalyse
