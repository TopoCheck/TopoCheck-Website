Entstehungsort des Projekts

Die Diplomarbeit TopoCheck entsteht an der HTL Wien 3 Rennweg. Die Schule ist weder Verantwortliche für diese Website oder die damit verbundene Datenverarbeitung noch Kontakt- oder Zustelladresse des Projektteams.

Hosting über GitHub Pages

Diese Website wird über GitHub Pages bereitgestellt. Beim Aufruf der Website können durch GitHub technische Zugriffsdaten verarbeitet werden. Dazu können insbesondere IP-Adresse, Datum und Uhrzeit des Zugriffs, aufgerufene Seite, übertragene Datenmenge, Browsertyp und Betriebssystem gehören. Diese Verarbeitung ist für die sichere und zuverlässige Bereitstellung der Website erforderlich. Weitere Informationen enthält die Datenschutzerklärung von GitHub.

Google Fonts

Zur einheitlichen Darstellung von Schriftarten verwendet diese Website Google Fonts. Die Schriftarten werden beim Seitenaufruf von Servern von Google geladen. Dabei wird insbesondere die IP-Adresse des verwendeten Geräts an Google übertragen. Anbieter ist Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Irland. Weitere Informationen enthält die Datenschutzerklärung von Google.

Speicherung der Farbschema-Auswahl

Wenn zwischen hellem und dunklem Design gewechselt wird, speichert die Website diese Auswahl im lokalen Speicher des Browsers. Dadurch bleibt die Einstellung bei einem späteren Besuch erhalten. Diese Information verbleibt auf dem verwendeten Gerät, enthält keine unmittelbar personenbezogenen Angaben und wird nicht an uns übertragen.

Kontakt per E-Mail

Bei einer Kontaktaufnahme per E-Mail werden die übermittelten Angaben ausschließlich zur Bearbeitung der Anfrage und für mögliche Anschlussfragen verarbeitet. Die Daten werden nicht ohne Zustimmung an Dritte weitergegeben, sofern keine gesetzliche Verpflichtung besteht.

Cookies und Analyse

Diese Website setzt derzeit keine eigenen Cookies ein und verwendet keine Analyse-, Werbe- oder Trackingdienste.

Außerdem besteht das Recht, eine Beschwerde bei der Österreichischen Datenschutzbehörde einzureichen.
